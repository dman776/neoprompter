# Companion API and Producer page

Read this before touching `src/api/`, the Producer page, or the quick-message list. Companion button setup examples are in `companion.md`.

`src/api/` is the local HTTP service (Node `http`, no framework). `createApiServer({ core, port, token?, extraRoutes? })` has `start()` (rejects with a readable message when the port is taken), `stop()`, `setToken()`. Request flow lives in one place: (1) remote-address gate, 403; (2) token, 401 (applies to every route, the Producer page and unknown routes included; it arrives as `Authorization: Bearer`, an `X-Neoprompter-Token` header, or as the password of HTTP Basic whatever the username; never a `?token=` query string; with no token set everything is open); (3) route lookup, 404/405; (4) body cap (4 KB, 413). Built-in routes are only `POST /api/notify {text, durationMs?}` and `GET /api/status`, listed in `ROUTES`; there is deliberately no transport or Script endpoint, and `api.test.ts` asserts the table and probes transport-like paths. The Producer page (`src/api/producer.ts`, `producerPage.ts`) is added via `extraRoutes`: `GET /` (static inline HTML behind the same token check as every other route: a 401 carries `WWW-Authenticate: Basic`, so the Producer's browser shows its own password box, takes the token as the password, and then sends it on the page's later requests itself; the page holds and stores no token, and the token is never embedded or put in a URL), plus `GET`/`POST /api/quick-messages` for the shared quick-message list (persisted in `quick-messages.json` by `src/main/fileQuickMessageStore.ts`). `producer.test.ts` asserts that route table; `api.test.ts` asserts the built-ins.

"Local network only" as built: the server binds `0.0.0.0` (so LAN devices can reach it) and every request is checked against the socket peer address with `isPrivateAddress`: loopback, RFC 1918 (10/8, 172.16/12, 192.168/16), IPv4 link-local, IPv6 loopback/unique-local/link-local, and IPv4-mapped forms. Anything else gets 403. It does not stop a public-routable address on this machine from being bound; it relies on the check, and on the router not forwarding the port. Port (default 4780, 1024-65535) and optional token persist in `api-settings.json` in userData (`src/main/fileApiSettingsStore.ts`), edited in Preferences, Network (`src/preferences/NetworkPage.tsx`, which also edits the Quick messages through the main process); `src/main/apiController.ts` restarts the server on port change. Companion setup examples: `docs/companion.md`.
